# Расстояние редактирования

Программа считает, сколько вставок, удалений и замен символов нужно, чтобы
превратить одну строку в другую. Каждая операция стоит 1. Например, для
`кот` и `кит` достаточно одной замены. Перестановка соседних символов не
считается отдельной операцией.

## Запуск

Нужен Python 3.9 или новее. Из папки проекта:

```bash
python edit_distance.py кот кит
```

Результат:

```text
Расстояние: 1
```

Если в аргументе есть пробелы, заключите его в кавычки.

## Тесты

```bash
python -m unittest -v
```

## Сложность

Для строк длиной `m` и `n` время работы — `O(m × n)`. Хранятся только две
строки таблицы, поэтому дополнительная память — `O(min(m, n))`.

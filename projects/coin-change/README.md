# Минимальное число монет

Программа подбирает наименьшее число монет, которыми можно набрать заданную
сумму. Номиналы можно указать в любом порядке. Если сумму набрать нельзя,
программа сообщит об этом.

Алгоритм последовательно вычисляет ответ для каждой суммы от нуля до нужной.
Он учитывает все заданные номиналы, поэтому работает и в случаях, где выбор
самой крупной подходящей монеты даёт неоптимальный результат.

## Запуск

Нужен Python 3.10 или новее. Из папки проекта:

```bash
python coin_change.py 6 1 3 4
```

Результат:

```text
Количество монет: 2
Монеты: 3 3
```

При сумме `7` и номиналах `2 4` выводится `Сумму набрать нельзя.`

## Тесты

```bash
python -m unittest -v
```

Для суммы `S` и `M` различных номиналов время работы — `O(S · M)`,
дополнительная память — `O(S + M)`.

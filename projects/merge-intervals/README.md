# Слияние интервалов

Программа читает числовые интервалы из файла, сортирует их и объединяет
пересекающиеся. Если у двух интервалов общая граничная точка, они тоже
объединяются. Между `1 3` и `4 5` общей точки нет, поэтому они остаются
раздельными.

В каждой непустой строке файла должны быть два целых числа: начало и конец
интервала. Начало не может быть больше конца. Порядок строк не важен.

## Запуск

Нужен Python 3.9 или новее. Из папки проекта:

```bash
python merge_intervals.py example.txt
```

Результат:

```text
1 6
8 12
15 18
```

Для пустого файла выводится `Интервалов нет.`.

## Тесты

```bash
python -m unittest -v
```

## Сложность

Для `n` интервалов сортировка занимает `O(n log n)` времени. Дополнительная
память для результата и отсортированного списка — `O(n)`.

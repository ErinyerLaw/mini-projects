# Перенос строк текста

Программа читает текстовый файл и переносит слова так, чтобы строка не была
шире заданного числа символов. Пустые строки сохраняются, а несколько
пробелов между словами заменяются одним. Слова длиннее заданной ширины
остаются целыми на отдельной строке. Каждая строка исходного файла
обрабатывается отдельно.

## Сборка и запуск

Нужен компилятор с поддержкой C++17. Из папки проекта:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic text_wrap.cpp main.cpp -o text_wrap
./text_wrap 10 example.txt
```

В PowerShell после сборки запускайте `./text_wrap.exe 10 example.txt`.
Пример вывода:

```text
red green
blue

one two
three
```

Ширина считается в байтах, поэтому пример использует латинские буквы.

## Тесты

```bash
g++ -std=c++17 -Wall -Wextra -pedantic text_wrap.cpp text_wrap_test.cpp -o text_wrap_test
./text_wrap_test
```

В PowerShell тестовая программа называется `text_wrap_test.exe`.
При успешном выполнении она ничего не выводит.

# Кратчайший путь в лабиринте

Небольшая программа на JavaScript ищет путь от `S` до `G` в текстовом
лабиринте. Она использует поиск в ширину (BFS), поэтому найденный путь
содержит минимальное число шагов. Маршрут отмечается символами `*`.

Проект показывает работу с графом-клетчаткой, очередью, восстановление
пути по предыдущим клеткам, проверку ввода и тесты без внешних пакетов.

## Запуск

Нужен Node.js 18 или новее. Из папки проекта:

```bash
node maze.mjs example.txt
```

Формат файла: каждая строка — ряд лабиринта одинаковой длины. `S` — старт,
`G` — цель, `#` — стена, `.` — свободная клетка. Ходить можно вверх, вниз,
влево и вправо.

Для `example.txt` программа выводит:

```text
Шагов: 8
S**#G
##*#*
..***
```

Если цель недостижима, выводится `Путь не найден.`

## Тесты

```bash
node --test maze.test.mjs
```

Тесты проверяют кратчайший маршрут, отсутствие пути, переносы строк Windows,
ошибки формата и недопустимые символы.

## Сложность

Для лабиринта из `H` строк и `W` столбцов время работы и дополнительная
память составляют `O(H × W)`: каждая доступная клетка попадает в очередь
не более одного раза.

# Кратчайший путь в лабиринте

Программа на C++ ищет путь от `S` до `G` в текстовом лабиринте. Поиск в ширину
(BFS) находит маршрут с минимальным числом шагов; клетки маршрута отмечаются
символами `*`.

## Сборка и запуск

Нужен компилятор с поддержкой C++17. Из папки проекта:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic maze.cpp main.cpp -o maze
./maze example.txt
```

В PowerShell после сборки запускайте `./maze.exe example.txt`.

Формат файла: строки одинаковой длины; `S` — старт, `G` — цель, `#` — стена,
`.` — свободная клетка. Ходить можно вверх, вниз, влево и вправо.

Для `example.txt` программа выводит:

```text
Шагов: 8
S**#G
##*#*
..***
```

Если путь отсутствует, выводится `Путь не найден.`

## Тесты

```bash
g++ -std=c++17 -Wall -Wextra -pedantic maze.cpp maze_test.cpp -o maze_test
./maze_test
```

На Windows исполняемый файл называется `maze_test.exe`.

## Сложность

При `H` строках и `W` столбцах время и дополнительная память составляют
`O(H × W)`: каждая доступная клетка обрабатывается не более одного раза.

# Часто встречающиеся числа

Программа читает целые числа из файла и показывает `K` чисел с наибольшей
частотой. Если частоты совпадают, сначала выводится меньшее число. Если
различных чисел меньше `K`, выводятся все.

## Сборка и запуск

Нужен компилятор с поддержкой C++17. Из папки проекта:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic top_k.cpp main.cpp -o top_k
./top_k 2 example.txt
```

В PowerShell после сборки запускайте `./top_k.exe 2 example.txt`.
В `example.txt` записано `4 1 4 2 1 4`. Результат:

```text
4: 3
1: 2
```

При `K = 0` или пустом файле выводится `Нет результатов.`

## Тесты

```bash
g++ -std=c++17 -Wall -Wextra -pedantic top_k.cpp top_k_test.cpp -o top_k_test
./top_k_test
```

В PowerShell тестовая программа называется `top_k_test.exe`. При успешном
выполнении она ничего не выводит.

Для `N` чисел и `U` различных значений подсчёт и сортировка занимают
`O(N + U log U)` времени в среднем и `O(N + U)` памяти с учётом хранения
входных чисел.

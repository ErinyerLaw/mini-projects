# Порядок задач

Программа составляет порядок выполнения задач с зависимостями. Каждая строка
файла содержит название задачи, двоеточие и названия задач, которые нужно
выполнить раньше. Названия пишутся без пробелов. Если зависимость не объявлена
или задачи образуют цикл, программа сообщает об ошибке.

Используется топологическая сортировка. Если возможны несколько правильных
порядков, программа выводит один из них.

## Запуск

Нужен Python 3.9 или новее. Из папки проекта:

```bash
python task_order.py example.txt
```

Результат:

```text
1. покупки
2. готовка
3. ужин
4. уборка
```

## Тесты

```bash
python -m unittest -v
```

## Сложность

Для `V` задач и `E` зависимостей время и дополнительная память составляют
`O(V + E)`.

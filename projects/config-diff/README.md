# Сравнение настроек

Программа сравнивает два текстовых файла настроек и показывает добавленные,
удалённые и изменённые параметры. Каждая строка имеет вид `key=value`.
Пустые строки и строки, начинающиеся с `#`, пропускаются. Пробелы по краям
имён и значений удаляются; знак `=` внутри значения допустим.

## Сборка и запуск

Нужен компилятор с поддержкой C++17. Из папки проекта:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic config_diff.cpp main.cpp -o config_diff
./config_diff old.conf new.conf
```

В PowerShell после сборки запускайте `./config_diff.exe old.conf new.conf`.

Для файлов из примера вывод будет таким:

```text
+ timeout = 30
- debug = true
~ port: 8080 -> 9090
```

Если различий нет, программа выводит `Различий нет.`. Повторяющиеся имена
параметров и строки без `=` считаются ошибкой.

## Тесты

```bash
g++ -std=c++17 -Wall -Wextra -pedantic config_diff.cpp config_diff_test.cpp -o config_diff_test
./config_diff_test
```

В PowerShell тестовая программа называется `config_diff_test.exe`. При
успешном выполнении она ничего не выводит.

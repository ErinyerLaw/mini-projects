# Просмотр байтов файла

Программа показывает содержимое файла в шестнадцатеричном виде. В каждой
строке — смещение, до восьми байтов и их ASCII-представление. Непечатные
байты отображаются точкой. Файл читается как набор байтов, поэтому программа
подходит и для текстовых, и для двоичных файлов.

## Сборка и запуск

Нужен компилятор с поддержкой C++17. Из папки проекта:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic hex_view.cpp main.cpp -o hex_view
./hex_view example.txt
```

В PowerShell после сборки запускайте `./hex_view.exe example.txt`.

Файл `example.txt` содержит `Hello` без символа перевода строки. Вывод:

```text
00000000: 48 65 6c 6c 6f |Hello|
```

## Тесты

```bash
g++ -std=c++17 -Wall -Wextra -pedantic hex_view.cpp hex_view_test.cpp -o hex_view_test
./hex_view_test
```

В PowerShell тестовая программа называется `hex_view_test.exe`. При
успешном выполнении она ничего не выводит.

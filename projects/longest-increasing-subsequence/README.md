# Самая длинная возрастающая подпоследовательность

Программа получает целые числа и находит одну из самых длинных строго
возрастающих подпоследовательностей. Числа в ответе идут в том же порядке,
что и во входе, но между ними могут быть пропуски. Равные числа не считаются
возрастанием.

## Запуск

Нужен Python 3.10 или новее. Из папки проекта:

```bash
python lis.py 3 1 2 5 4
```

Результат:

```text
Длина: 3
Подпоследовательность: 1 2 4
```

Если чисел нет, программа выводит длину `0` и `Подпоследовательность: нет`.

## Тесты

```bash
python -m unittest -v
```

Алгоритм хранит наименьший возможный последний элемент для каждой длины и
находит место нового числа двоичным поиском. Для `N` чисел время работы —
`O(N log N)`, дополнительная память — `O(N)`.

# Mini Projects

Коллекция небольших законченных проектов и реализаций алгоритмов. Каждый проект
лежит в отдельной папке, содержит инструкции по запуску и проверяется тестами.

## Каталог проектов

Проекты добавляются постепенно.

## Принципы

- понятный код без лишней сложности;
- минимум внешних зависимостей;
- воспроизводимые примеры запуска;
- тесты для основной логики.
